# ABHISHEK.OS

Interactive agentic portfolio V1.

## Current V1
- CV-backed portfolio data
- Interactive agent-style chat UI
- Agent Lab execution trace (local demo)
- Terminal mode
- Agent Network
- Projects explorer
- Owner Protocol prototype gate

## Run locally

Requirements: Node.js 20+ recommended.

```bash
npm install
npm run dev
```

Open http://localhost:3000
